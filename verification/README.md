# Verification

This directory collects verification and research artifacts separately from
the publishable `massively` crate.

- [`proof/`](proof/) contains the Massively Core Lean proof.
- [`oracle/`](oracle/) contains independent CPU references and property tests
  for the public vector and segment operations.
- [`graph-algorithms/`](graph-algorithms/) contains complete graph algorithms
  composed from those operations and their independent CPU oracle tests.
